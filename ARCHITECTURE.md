# ТЕХНИЧЕСКИЙ ПАСПОРТ И БИЗНЕС-ПЛАН ПРОЕКТА: KITCHEN AI
## ИИ-сервис автоматического проектирования и подготовки к производству кухонных гарнитуров (ViyarPro Ecosystem)

---

## 1. Резюме проекта (Executive Summary)

* **Продукт:** B2B SaaS-платформа в формате Telegram Mini App (TMA) для мебельщиков и дизайнеров. Принимает данные замера из Bosch MeasureOn, считывает коммуникации через Vision AI, генерирует клиентскую фото-визуализацию гарнитура и формирует исполняемый скрипт сборки 3D-модели в SketchUp с присадкой, кромкой и выгрузкой на фабрику «Вияр».
* **Целевой рынок:** Частные мебельщики, дизайнеры интерьера, мебельные цеха (Украина, адаптация под экосистему ViyarPro).
* **Главная ценность:** Сокращение времени от замера до отправки заказа в производство с **6–8 часов до 15 минут**, быстрая визуализация для клиента, исключение математических ошибок, полная защита параметрических формул (IP).

## 2. Стек технологий и рабочее окружение

* **Среда выполнения:** Windows (локальная разработка и тестирование) ──► Linux / Docker (промышленный сервер).
* **Язык разработки & Backend:** Python 3.12+ / FastAPI.
* **ИИ-Engine (Vision & Logic):** Google Gemini API (`Gemini Flash Vision` — считывание $X, Z$ координат с фото; `Gemini Pro/Flash` — выбор состава модулей).
* **ИИ-Engine (Image Gen):** Flux API / Imagen 3 API (генерация фотореалистичных концептов интерьера для клиента).
* **Инструменты разработки (IDE & AI):** 
  * VS Code + виртуальное окружение `venv`.
  * **Continue (расширение VS Code) + Gemini API:** ИИ-кодер прямо в редакторе.
  * **Веб-чат Gemini:** Главный архитектор системы и проектировщик логики.
* **Библиотеки Python:** `pdfplumber` (парсинг PDF), `google-genai` (Vision API), `pydantic` (валидация), `python-dotenv` (управление ключами), `jinja2` (генератор Ruby-скриптов).
* **Клиентский CAD:** SketchUp Desktop + Ruby API.

## 4. Подробная спецификация модулей

### А. Модуль 1: Входной поток и Интерфейс (Bosch + TMA)
1. **Bosch MeasureOn:** Замер геометрии (Bluetooth-дальномер) + Photo Measure (нанесение стрелок от угла $X$ и пола $Z$ до коммуникаций).
2. **`bosch_parser.py`:** Парсер текстовых замеров стен/потолков из PDF отчета.
3. **`vision_parser.py`:** Передача фото с разметкой в Gemini Flash Vision для считывания точных координат инженерных выводов.
4. **Telegram Mini App:** Быстрый ввод пользовательских предпочтений (тип ПММ, холодильника, цвет фасадов).

### Б. Модуль 2: Серверная логика и Генерация (Python FastAPI)
* **LLM (ИИ):** Выступает в роли дизайнера — определяет эргономический состав кухни.
* **Image AI Engine:** Формирует промпт из параметров JSON и генерирует эскиз кухни для согласования с клиентом до этапа 3D.
* **Python Math:** Инженерный расчет — жесткая арифметика $X, Y, Z$ (алгоритм «Паровозик», исключающий галлюцинации).
* **Jinja2:** Формирует итоговый `kitchen_script.rb`.

### В. Модуль 3: Клиентский 3D-движок (SketchUp)
* **Защита IP:** Ruby-скрипт расставляет шкафы, пересчитывает формулы и удаляет словарь `AttributeDictionary`. Мастер получает «чистую» геометрию без доступа к параметрическим исходникам.
* **Выгрузка:** Модель на 100% совместима со штатным плагином ViyarPro для передачи деталировки на раскрой и ЧПУ.
